# 32-bit Parameterized ALU Design

## Project Overview
A 32-bit parameterized Arithmetic Logic Unit (ALU) designed using Verilog HDL.

## Features
- Arithmetic operations
- Logical operations
- Shift and rotate operations
- Comparison operations
- Status flags

## Tools Used
- Verilog HDL
- Cadence RTL Compiler
- SDC Constraints
- TCL Synthesis Script
